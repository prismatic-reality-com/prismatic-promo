# E-mail šablony pro test responzivity

**Účel**: Před zadáním mandátu otestovat (a) rychlost odpovědi, (b) kvalitu právní analýzy, (c) profesionalitu komunikace AK.

---

## Šablona 1 — Iniciální dotaz (pošlete v pondělí ráno cca 9:00)

```
Předmět: Dotaz k poskytnutí právních služeb — [vaše jméno / firma]

Vážený pane Mgr. Procházko,

obracím se na Vás jménem [klient — plný název nebo plné jméno FO] (IČO [___], sídlo [___])
s žádostí o úvodní konzultaci ohledně případné dlouhodobé spolupráce
v oblasti právních služeb.

Stručné představení:
- [klient = popis činnosti, sektor, velikost (obrat / zaměstnanci)]
- [aktuální právní servis — interní / externí (kdo) / žádný]
- [důvod pro hledání nové AK — růst / nespokojenost / nový projekt]

Máme zájem o:
- pravidelný měsíční retainer pro generalistický servis
- ad-hoc projektovou pomoc v oblastech: [obchodní / civilní / správní / další]
- předpokládaný objem cca [__] hodin/měsíc

Konkrétní úvodní téma, ke kterému bychom rádi slyšeli Vaše předběžné stanovisko:

[POPIS KONKRÉTNÍHO PRÁVNÍHO PROBLÉMU — viz Šablona 2 níže pro varianty]

Bylo by možné domluvit si úvodní 30–45min schůzku ve vaší kanceláři
(ideálně do 2 týdnů od dnešního data) a stručně vyjádřit předběžný názor
na výše uvedený problém v této e-mailové korespondenci?

Děkujeme předem za Vaši odpověď.

S pozdravem
[vaše jméno]
[funkce]
[telefon]
[e-mail]
[firma + IČO]
```

## Šablona 2 — Varianty konkrétního právního dotazu

Vyberte **jeden** dotaz dle vaší skutečné potřeby (test funguje nejlépe, když dotaz je reálný a netriviální).

### Varianta 2A — obchodní právo / smluvní

```
Konkrétní dotaz:
Plánujeme uzavřít rámcovou smlouvu s dlouhodobým dodavatelem
(předmět: [SW vývoj / dodávka materiálu / služby], hodnota cca [X] mil. Kč/rok,
trvání 3 roky). Protistrana navrhuje:

a) volbu práva: anglické právo
b) sudiště: rozhodčí soud při HK ČR Praha
c) cap odpovědnosti: 1× roční hodnota plnění
d) výpovědní lhůtu: 90 dní bez sankce

Předběžně: doporučujete přijmout, vyjednávat změny, nebo navrhnout
zcela jinou strukturu? Stačí stručný odhad rizik (3–5 bodů) — ne kompletní analýzu.
```

### Varianta 2B — pracovní právo

```
Konkrétní dotaz:
Plánujeme implementaci agenda whistleblowingu dle z. č. 171/2023 Sb.
(klient má 80 zaměstnanců, několik provozoven). Konkrétně:

1. Musíme zřídit interní oznamovací kanál i externí?
2. Lze pověřit externího prošetřovatele (např. Vaši AK), nebo musí být interní?
3. Je možné zveřejnit informace o oznámeních anonymně v interním reportu?

Stačí stručná odpověď s odkazem na konkrétní paragrafy zákona.
```

### Varianta 2C — civilní / spor

```
Konkrétní dotaz:
Náš odběratel je v prodlení s úhradou faktury 850 000 Kč splatné 31. 1. 2026.
Telefonicky uvádí likviditní problémy, ale nepodal insolvenční návrh.

Doporučujete:
a) podání insolvenčního návrhu za nás (věřitelského)?
b) žalobu k OS dle bydliště dlužníka (a poté výkon rozhodnutí)?
c) prodej pohledávky inkasní agentuře?

Jakou hodinovku byste si účtoval(a) za přípravu insolvenčního návrhu
a za zastupování v navazujícím řízení?
```

### Varianta 2D — real estate

```
Konkrétní dotaz:
Plánujeme akvizici obchodního prostoru v Brně (cca 200 m², přízemí,
hodnota cca 18 mil. Kč). Prodávající je s.r.o. ovládaná FO.

Ceníme si:
1. Kompletní DD nemovitosti (vlastnictví, závazky, věcná břemena, územní plán)
2. Strukturování transakce (přímý vs. share deal — daňová optimalizace)
3. Drafting + negociace SPA + escrow účtu
4. Zápis do KN

Můžete prosím poslat:
a) předběžný odhad fixní ceny za balíček (transakce do 30 mil. Kč),
b) alternativně hodinovku per role + odhadovaný počet hodin,
c) reference z 2–3 podobných transakcí (anonymizovaně)?
```

### Varianta 2E — správní / veřejné zakázky

```
Konkrétní dotaz:
Účastnili jsme se otevřeného nadlimitního výběrového řízení města
(předmět: dodávka [___], hodnota 25 mil. Kč). Naše nabídka byla
vyhodnocena jako 2. nejvýhodnější. Vítěz účastnil řízení s ceníkem,
který je dle našeho názoru mimořádně nízký a nemá ekonomické opodstatnění.

Doporučujete:
1. Námitku zadavateli dle § 241 z. č. 134/2016 Sb. (lhůta 15 dnů)?
2. Návrh ÚOHS na přezkum?
3. Obojí paralelně?

Jaký je Váš odhad pravděpodobnosti úspěchu při napadení mimořádně
nízké nabídky a jaké argumenty/důkazy by bylo třeba předložit?
```

## Hodnotící matice odpovědi (pro vás interně)

Po obdržení odpovědi vyhodnoťte:

| Kritérium | Score 0–10 | Poznámka |
|-----------|------------|----------|
| **Čas reakce** | | <4 h = 10, <24 h = 8, <48 h = 5, >48 h = 0 |
| **Personalizovaná vs. šablonovitá** | | osobní text vs. generic boilerplate |
| **Substantivní právní obsah** | | konkrétní paragrafy, judikatura, návrh řešení |
| **Identifikace klíčových rizik** | | rozeznal rizika, která jste sami neidentifikovali? |
| **Proaktivní follow-up** | | nabídl další kroky / dotazy |
| **Profesionalita formy** | | gramatika, stylistika, oslovení |
| **Cenová transparentnost** | | uvedl předběžné odhady? |
| **Reference / důvěra** | | zmínil podobný případ / specializaci? |
| **Časová flexibilita** | | nabídl rychle úvodní schůzku? |

**Skóre 70+/90** = silný kandidát.
**Skóre 50–70** = průměrný, vyžaduje další ověření.
**Skóre <50** = červená vlajka — zvažte vyřazení.

## Šablona 3 — Pokud do 24 h nepřišla odpověď (eskalace)

```
Předmět: Re: Dotaz k poskytnutí právních služeb — [vaše jméno]

Vážený pane Mgr. Procházko,

dovoluji si připomenout svůj e-mail z [datum]. Předem děkujeme za odpověď
a v případě, že je termín úvodní schůzky pro Vás příliš úzký,
ocenil bych alespoň krátké potvrzení, že jste e-mail obdržel.

S pozdravem
[vaše jméno]
```

## Šablona 4 — Pokud po 48 h stále bez odpovědi

**Doporučení**: vyřaďte AK ze short-listu a oslovte alternativy z `06-reports/02-shortlist-konkurence.md`. Responzivita je kritický indikátor — pokud AK nereaguje na první kontakt, neočekávejte rychlou reakci v urgentních situacích.

---

## Best practice

- **Pošlete dotaz minimálně 3 alternativním AK** (např. Procházka & Co. + Štourač + Fiala/Tejkal) ve **stejný den**, **se stejným textem** — porovnání je férové.
- **Sledujte čas reakce** — nejen kvalitu obsahu.
- **Neuvádějte v dotazu, že testujete** — odpověď bude méně autentická.
- **Po obdržení odpovědí** vyhodnoťte hodnotící maticí.
- **Přijměte pozvání na úvodní schůzku** od 1–2 nejlépe hodnocených AK; teprve poté finalizujte výběr.
