🧪 DD Workspace — Spouštěč povrchových testů

Ověřuje, že se všechny HTML stránky načtou, že každý odkazovaný markdown zdroj je dostupný přes in-browser store a že jsou připojeny hlavní JS API. Spusťte po startu ./serve.sh.

· ·

Tato stránka používá _assets/test-console.js (window.DD_TEST) plus skrytý iframe sondu. HTML se načítají přes fetch (pro HTTP status + tělo) a sekundárně přes iframe pro ověření, že se vykreslí. Markdown zdroje se hledají přes window.DD_MD_STORE_GET, pokud je k dispozici; jinak fallback na fetch.
