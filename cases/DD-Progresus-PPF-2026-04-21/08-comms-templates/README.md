## 🔑 Klíčová zjištění

- 🟢 **Sekvence je důležitá** — doporučené pořadí: (6) měření teploty Savills → (1) NDA → (3) DANCORE proaktivní → (5) ČNB §23a (pokud je PPF banka potvrzena) → (4) souhlas vlastníků dluhopisů → (2) odpovědní rámec DD běží průběžně → (7) šablona debriefingu se spouští po každém kontaktu.
- 🔴 **Proaktivní zveřejnění DANCORE je nejkritičtější dopis pro transakci** — jít první u RF-26 neutralizuje největší úhel páky PPF pro úschovu. Před odesláním musí být perfektně vyladěn + zkontrolován právním zástupcem.
- 🔴 **Žádost o stanovisko ČNB §23a je časově citlivá** — pokud se PPF banka objeví v dluhové struktuře, žádost o stanovisko (lhůta 2–4 týdny) musí být podána před podpisem.
- 🟢 **NDA je oboustranná s vymahatelnými zuby**: (1) jmenovaný seznam exkluzivity vůči zájemcům (Karlín + 7 konkurentů uzamčeno), (2) vzájemná 8týdenní exkluzivita, (3) symetrické prohlášení o střetu zájmů.
- 🟢 **Žádost o souhlas vlastníků dluhopisů architektována napříč 68 tranšemi, 5 prospekty, 7,6+ mld. Kč** — okno 60–90 dní, prioritní sekvence top 10 institucionálních.
