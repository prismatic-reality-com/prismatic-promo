## Overview

The **Code Review Specialist Agent v2.0** is an L4 autonomous agent within the Prismatic Platform's [AIAD ecosystem](@/agents/_index.md). Operating in the **development** domain, this agent delivers specialized capabilities that integrate with the platform's multi-agent orchestration framework under the [NO MERCY, NO DOUBTS](@/glossary/no-mercy-no-doubts.md) doctrine.

Autonomous AIAD agent providing specialized capabilities within the Prismatic Platform development domain.

## Operational Domain

This agent operates within the **development** domain of the Prismatic Platform, contributing to the platform's comprehensive coverage of enterprise intelligence, security, and development automation. All operations comply with the [AIAD standard](@/glossary/aiad.md), ensuring vendor-neutral interoperability across the agent ecosystem.

The agent coordinates with peer agents through the platform's mycelial network, enabling emergent behaviors and collaborative problem-solving that exceed the capabilities of any individual agent. Communication follows structured protocols with typed message passing and priority-based routing.

## Key Capabilities

- **Autonomous execution**: Self-directed operation within defined authority boundaries and quality constraints

- **Multi-agent coordination**: Integration with the platform's 1,090+ agent ecosystem through structured communication protocols

- **Quality gate compliance**: All outputs validated against the platform's zero-tolerance quality standards

## Architecture Integration

The Code Review Specialist Agent v2.0 integrates with the Prismatic Platform through the standard AIAD agent lifecycle:

1. **Registration**: Auto-discovered at platform startup and registered in the agent registry
2. **Activation**: Instantiated on demand through the orchestration layer or direct invocation
3. **Execution**: Processes tasks within its authority level (L4) with full telemetry
4. **Coordination**: Communicates results to dependent agents and the mycelial network
5. **Evolution**: Participates in the platform's autonomous evolution cycles

### Authority Level

Operating at **L4** authority, this agent has:

- Tactical autonomy within its domain boundaries
- Escalation paths to higher-authority agents when decisions exceed scope
- Integration with the platform's supervision tree for fault tolerance
- Compliance with all quality gates and doctrine requirements

## Doctrine Compliance

All operations enforce the platform's core doctrines:

- **[NO MERCY](@/glossary/no-mercy.md)**: Zero tolerance for incomplete implementations, untested code, or quality violations
- **[NO DOUBTS](@/glossary/no-doubts.md)**: Full investigation before action, decisive execution, evidence-based decisions
- **[NABLA Infinity](@/glossary/nabla-infinity.md)**: Signal plurality, contradiction preservation, provenance mandatory
- **[Trinity Gate](@/glossary/trinity-gate.md)**: Structural, logical, and formal verification of all claims
