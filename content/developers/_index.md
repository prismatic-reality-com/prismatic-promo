## 🚀 Quick Start

Get started with Prismatic development in under 5 minutes:

### Installation

```bash
# Node.js/TypeScript
npm install @prismatic-platform/sdk
npm install @prismatic-platform/ui-components

# Elixir
{:prismatic_sdk, "~> 0.1.0"}
{:prismatic_adapters, "~> 0.1.0"}

# Python
pip install prismatic-sdk
```

### Your First Intelligence Query

```javascript
import { PrismaticSDK } from '@prismatic-platform/sdk';

const sdk = new PrismaticSDK({
  apiKey: process.env.PRISMATIC_API_KEY,
  endpoint: 'https://api.prismatic-platform.org'
});

// OSINT domain analysis
const analysis = await sdk.osint.analyzeDomain('example.com');
console.log('Security Rating:', analysis.security_rating);
console.log('Risk Factors:', analysis.risk_factors);
```

### Sample Plugin

```elixir
defmodule MyIntelligence.CustomAdapter do
  @behaviour PrismaticAdapters.SourceBehaviour

  @impl true
  def search(query, opts \\ []) do
    # Your custom intelligence source
    with {:ok, data} <- fetch_external_data(query),
         {:ok, parsed} <- parse_response(data) do
      {:ok, %{
        confidence: 0.85,
        source: __MODULE__,
        data: parsed,
        metadata: %{timestamp: DateTime.utc_now()}
      }}
    end
  end
end
```

### Prismatic Plugin Kit

**Repository**: [`prismatic-platform/prismatic-plugin-kit`](https://github.com/prismatic-platform/prismatic-plugin-kit)
**License**: MIT
**Languages**: TypeScript, JavaScript
**Status**: Alpha Release (v0.3.0)

Framework for building custom intelligence adapters and analysis plugins:

- **Adapter Templates**: Scaffolding for OSINT sources, threat feeds, and custom APIs
- **Pipeline Components**: Reusable data transformation and enrichment functions
- **Testing Framework**: Contract tests ensuring adapter compliance
- **Documentation Generator**: Auto-generated docs from adapter schemas

```javascript
// Create custom intelligence adapter
import { createAdapter } from '@prismatic-platform/plugin-kit';

export const customThreatFeed = createAdapter({
  name: 'custom-threat-feed',
  version: '1.0.0',
  description: 'Custom threat intelligence source',

  schema: {
    query: z.object({
      indicator: z.string(),
      types: z.array(z.enum(['ip', 'domain', 'hash'])).optional()
    }),
    response: z.object({
      confidence: z.number().min(0).max(1),
      threat_type: z.string(),
      first_seen: z.date(),
      attributes: z.record(z.any())
    })
  },

  async execute(query) {
    // Implement your custom logic
    const data = await fetchThreatData(query.indicator);
    return {
      confidence: calculateConfidence(data),
      threat_type: data.category,
      first_seen: new Date(data.timestamp),
      attributes: data.metadata
    };
  }
});
```

```elixir
# Elixir example - Custom adapter implementation
defmodule MyApp.CustomOSINTSource do
  @behaviour PrismaticAdapters.SourceBehaviour

  @impl true
  def capabilities do
    %{
      query_types: [:domain, :email, :ip],
      rate_limit: {100, :per_hour},
      confidence_range: {0.6, 0.95},
      data_freshness: :realtime
    }
  end

  @impl true
  def search(query, opts \\ []) do
    with {:ok, raw_data} <- api_call(query),
         {:ok, structured} <- parse_response(raw_data),
         confidence <- calculate_confidence(structured) do
      {:ok, %PrismaticAdapters.Result{
        source: __MODULE__,
        query: query,
        confidence: confidence,
        data: structured,
        metadata: %{
          timestamp: DateTime.utc_now(),
          query_time_ms: measure_time(),
          source_version: "1.0.0"
        }
      }}
    end
  end
end
```
