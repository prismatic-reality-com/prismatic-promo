### Key Capabilities

- **Real-time MCP Integration**: Charts fetch data from the `/api/v1/mcp` endpoint
- **Auto-refresh**: 30-second intervals with graceful fallbacks
- **Responsive Design**: Flowbite-compatible dark theme
- **Error Recovery**: Automatic retry with user-friendly error states
- **Cache Management**: Client-side caching with TTL for performance

## Technical Implementation

### Chart Container Pattern
```html
<div data-chart-type="bar"
     data-chart-data="platform.stats"
     data-chart-options='{"responsive":true}'>
  <!-- Canvas auto-generated by PrismaticCharts -->
</div>
```

### MCP Data Flow
1. **Discovery**: Auto-scan `[data-chart-type]` elements
2. **Data Fetch**: MCP request to specified endpoint
3. **Render**: Chart.js instance with Flowbite theme
4. **Stream**: SSE updates via `/api/v1/mcp/events`
5. **Cache**: Client-side TTL cache for performance

### JavaScript API
```javascript
// Access chart manager
window.PrismaticCharts.getChart('chart_id')
window.PrismaticCharts.refreshAllCharts()
window.ChartUtils.formatNumber(1234567) // "1.2M"
```
